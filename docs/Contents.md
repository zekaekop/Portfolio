<h2 id="faq">FAQ (Frequently Asked Questions) contents</h2>

FAQ app allows users to submit a question, and moderators to see that and write their own answers to be displayed to the user.

This works quite similiar to the Feedback application
And my other Imageboard project replicas.

The views can be found in adapters/web
And it also uses usecases.
